# System Audio Visualization

首版同时支持 macOS 与 Windows。低频驱动曲线伸缩，中高频驱动粒子与细节，提供强度滑块，保留原曲线辨识度；这部分已由用户确认。完整方案及仅 macOS 运行验收的边界已由用户最终确认。可观察验收集中在 brief.md 的 A1～A10，避免重复登记相同场景。

用户已确认本轮只进行 macOS 运行验收。Windows 保留完整实现，运行验收延期；缺少 Windows 环境不阻塞本轮交付，但必须明确标示 Windows 未验收。

用户在独立验收报告 8/10 通过后，明确接受将真实悬浮层播放/停播直接观察，以及 macOS 权限拒绝/撤销、物理输出切换/拔插和系统睡眠唤醒交互延期。本轮接受已有真实采集、真实 App 状态、事件链复核及受控测试作为相应交付证据；上述真机部分持续标记 NOT RUN / deferred，不构成本轮阻塞，也不宣称已实测通过。以下完整功能行为不因此缩减。

## 系统音频来源

macOS 14.2+ 使用 Core Audio taps；Windows 10 1703+ 与 Windows 11 使用 WASAPI shared-mode loopback。两端均实现真实系统输出采集，不以占位实现替代任何一端。功能跟随默认输出设备，不合并其他输出设备或提供按应用选择；不可采集的受保护内容不承诺响应。

音频默认关闭，用户开启后才启动采集和必要的授权流程。旧配置缺少音频字段时按默认关闭加载。保存开启后下次启动可恢复，但须同时满足平台支持、权限允许、悬浮层显示及未要求减少动态效果。低于音频能力最低版本时，不改变原有应用启动能力；新功能显示不支持。

不得以麦克风或模拟信号替代系统音频而标示成功。原始音频只短暂存在于本机内存用于分析，不保存为音频文件、日志或上传；仅将有界特征和运行状态传给前端。

## 曲线响应

将归一化后的低、中、高频能量及总音量作为现有 renderer 的瞬时输入，不写入持久化动画或曲线几何参数。音频映射采用以下语义：

- 低频：围绕曲线中心作有界等比整体尺度变化，保留对称关系和拓扑，使用足够的画布内边距，避免最大强度裁切。
- 中频：调制已有粒子沿路径行进的速度，以累计相位保持连续；不把粒子数量或速度变化解释为工作状态改变。
- 高频：调制沿曲线的有界局部细节和粒子表现，保持原曲线辨识度，不采用颜色闪烁或全窗抖动。静态轮廓、轨迹和粒子使用一致的变换，避免粒子脱离路径。

强度在 0～100% 内有界，默认 50%；0% 完全不叠加音频效果，100% 仍受几何、粒子和速度安全上限约束。输入使用统一攻击/释放平滑及静音门限，门限、平滑参数和频段划分由实施决定，首版不扩展为映射编辑器。

用户更改强度时相位连续，既有数学几何参数、六项动画设置、全局透明度和状态颜色值不被改写。切换曲线后共享音频输入继续作用于新曲线，同时遵守该方案本身的可视边界。

调制同时覆盖待机单曲线和已有多会话绘制分支，不得只改待机路径。曲线选择器缩略图及预览保留既有预览行为，首版不额外加入音频响应或新采集器；实际音频响应显示在桌面悬浮层，设置子区提供真实音量反馈。

静音、数据超过 500 ms 未更新、停止或故障时，旧特征立即判为失效；新增响应在随后 1 秒内平滑回归零。旧采集运行的迟到事件不得污染重启后的新运行。

## 设置与运行状态

在现有 Appearance 的 Renderer 区域增加紧凑音频子区，沿用无外框 fieldset、系统字体、深色中性背景和橙色交互强调。现有导航、曲线选择和状态颜色编辑不重构。

子区按顺序提供：系统音频开关、简短音源说明、强度滑块及百分比、真实采集状态及轻量音量反馈；仅在故障时显示相应帮助或重试。不开新设置 View，不增加平滑度或逐状态矩阵。关闭或不可用时强度值保留，控件展示为禁用。0% 仍允许查看真实音量反馈，不把零强度等同于关闭采集。

配置意图与实际状态分别维护，明确显示关闭、启动中、采集中、静音、已暂停、权限失败、不支持和设备故障；获得真实采集启动结果前不得宣称成功。音量反馈不得生成额外音源，也不得用演示值伪装输入。

音频开关和强度复用完整 settingsStore、设置校验、串行保存及 settings-changed 合并。View 卸载后值继续存在，切曲线、恢复曲线动画、恢复几何均不重置音频设置。新字段有默认值与范围校验；实时特征、错误和设备状态不进入设置文件。

支持 en/zh-CN、键盘和 390px 窄窗口，焦点与可读标签明确。只有离散状态变化适度播报，连续音量和频段数据不进入实时朗读区。减少动态效果时显示音频动效暂停说明，停止额外动画与无用采集，保留开关和强度意图，恢复该系统偏好后按意图恢复。

## 生命周期与边界

原生运行期拥有唯一采集器；不因窗口数、View 切换或 renderer 数量重复采集。多个会话流共享音频特征并继续表达各自原有状态。不得因音乐创建或结束会话、改变主子关系或覆盖状态颜色。

关闭功能、隐藏悬浮层或应用退出时停止采集并释放设备、线程及回调资源；隐藏暂停不会清除保存的开启意图。重新显示时清空旧特征并按意图启动。关闭设置窗口或切 View 本身不改变可见悬浮层的采集运行。

默认输出设备切换、设备恢复或睡眠恢复后自动尝试重建采集，重连期间按断流规则衰减且不重播旧帧。自动重试有界，失败后保持设备故障和手动重试操作，不忙等、不循环授权弹窗。

健康的音频设备在无播放时可以不发回调。首次等待显示“等待系统音频”和播放/权限检查帮助，不将无回调猜成权限拒绝或硬件断线，不消耗重试次数；播放后自动接收。已成功收到音频后暂停播放，过期能量归零并显示静音，后续播放仍可恢复。设备健康错误与实际睡眠恢复保持独立重连判断。

若操作系统无法注销 IOProc，先停止样本处理并保留仍可能被系统引用的回调上下文，拒绝在同一进程再次采集；展示需重启应用的明确说明，避免释放仍在使用的内存或假装普通重试可以恢复。

macOS 提供系统音频权限用途说明；拒绝或撤销授权后停止并显示正确权限恢复说明，用户修复权限后可主动重试。系统要求重新启动应用才能使权限生效时明确说明。失败不回退到麦克风，也不阻断应用原有非音频功能。

## 实施与验证边界

复用现有 Tauri 事件、Canvas 动画循环、平台分支和测试工具。平台采集与特征分析留在原生侧；前端只消费瞬时特征，不逐帧保存配置。音频事件节流，避免无界缓冲和原生/前端排队堆积。新增绑定依赖仅服务所需平台能力，不引入 UI 框架。

以独立频段信号检查映射，以全曲线目录和多会话场景检查形状、相位、颜色与边界；浏览器检查显示和交互；macOS 已有真实采集、静音、隐藏/恢复、设置保存重启、减少动态效果及资源释放证据。权限/设备/睡眠真机交互及真实悬浮层直接视觉观察按用户接受范围延期，持续保留 NOT RUN / deferred；其他缺少必要证据的项目仍可阻塞。编译或合成信号不替代 macOS 真实采集证据。

Windows 原生实现与平台边界纳入代码复核，本轮不要求 Windows 运行或编译环境，不为此新增远程执行、系统配置或工具安装。Windows 运行验收记为 NOT RUN / deferred，注明用户已接受延期，不进入本轮阻塞门禁且不能计作通过。若使用现成工具完成静态或编译检查，只报告其实际覆盖，不宣称已完成 Windows 功能验收。
