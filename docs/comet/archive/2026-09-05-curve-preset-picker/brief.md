# 目标

改善外观页中 20 个预设曲线的发现、比较和选择体验。用户已接受推荐的弹层曲线图库方向，并明确确认完整实施范围。

# 范围

- 原始需求：当前已有 20 个预设曲线，继续使用下拉条不够友好，希望调整，但尚无明确思路。
- 将现有曲线下拉框替换为当前曲线缩略图、名称和“更换”入口，按需打开 20 项曲线图库。
- 完整目标规格：`specs/curve-preset-picker/spec.md`。仅新增选择器能力，复用现有曲线、渲染器、设置保存和本地化。
- 目标界面：`src/settings.html` 的 Appearance / 外观页；现有行为位于 `src/settings.js`，曲线定义位于 `src/curves.js`，样式位于 `src/styles.css`。

## 当前事实

- 当前选择器为 `#curve-id` 原生 select，包含 20 个预设；现有名称、ID 和顺序均可复用。
- 设置页没有曲线 Canvas 预览，实际动画显示在独立桌面悬浮层。
- 切换曲线会调用 `restoreCurveAnimation()`，载入该曲线的粒子数量、尾迹跨度、循环时长、脉冲时长、旋转时长和描边宽度，随后自动保存。
- 外观页上下排列显示与动画控制区。20 项若始终展开，会把现有滑块进一步推至下方。
- 当前视觉使用系统无衬线字体、深色背景、橙色操作强调，面板圆角为 8px，控件圆角为 5px。
- 顶层设置页只挂载当前选中的内容，完整设置由共享 store 保存。曲线选择器须适应该挂载/卸载方式。
- 已通过运行中的本地页面查看当前外观布局；尚未进行原生运行时或新交互验收。

# 验收示例

完整验收场景统一位于目标规格的 `Scenario:` 段落，涵盖图库与真实轮廓、局部预览、应用、同项保留、关闭、保存失败、设置同步、键盘操作、窄窗本地化和减少动态效果。本节不重复生成验收项。

# 约束与不变量

- 采用 Operate（操作型）界面原则：按形状识别、清晰的应用动作、有限动画和稳定布局。
- 保留当前视觉体系。设计尺度为 DESIGN_VARIANCE=3、MOTION_INTENSITY=3、VISUAL_DENSITY=6，属于局部控件调整。
- 缩略图使用项目真实曲线采样或现有 renderer，不能用近似装饰图替代。
- 浏览预览不得接入自动保存链路，不得改变实际悬浮层；只有明确应用操作进入现有设置保存流程。
- 所有预览需遵守 reduced motion；离开视图或关闭选取面板时释放动画资源。

# 决策

- 已确认：需要改善 20 个预设的选择体验；用户回复“可以”，接受推荐的弹层曲线图库方向。
- 已确认：用户回复“确认”，授权按完整目标规格实施并验证。
- 调查方式：保留现有界面为视觉依据，只比较曲线选择控件的替代形式。

## 选定方向

- 当前曲线缩略图、名称和“更换”入口，打开按需出现的曲线图库。标准桌面窗口为 5 列、4 行，窄窗口减少列数。
- 默认显示静态真实轮廓，悬停或键盘聚焦时最多播放一个局部动画。所有图形均复用项目曲线定义，不复制数学公式。
- 点击或 Enter 应用新曲线及其现有六项默认动画值；保存成功后关闭并恢复焦点。再次确认当前项关闭图库，但不重置自定义参数、不发起多余保存。
- 打开时定位并标出当前曲线。关闭按钮、Esc 或点击遮罩只关闭，预览不写入设置。
- 保存中阻止重复提交；失败保持弹层打开并提供重试，重试不再次重置参数。继续复用现有保存队列和全局保存状态。
- 单个 Native Change 足以完成本次局部交互，目标紧密相关，不拆分子任务。

## 实施边界

主要影响 `src/settings.html`、`src/settings.js`、`src/styles.css`、`src/i18n.js` 和现有设置检查。优先使用原生 dialog 与按钮语义，保持曲线 ID、共享设置模型及保存接口兼容。`src/curves.js` 和 `src/halo.js` 作为复用能力，原则上不修改曲线或动画算法。
