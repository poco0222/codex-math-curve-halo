# Outcome

恢复融合光环的线条厚度；Halo 每次启动先空闲，只显示本次启动后事件产生的会话状态，避免历史思考态复活；光晕由用户选择，默认关闭。

# Scope

- 用户原始反馈：昨天加入多色多状态融合，整体线条变细；没有线程工作时打开即出现黄色思考态和四条运动线条。
- 调查 8a9c320 的绘制变化、快照有效期、启动恢复与本地快照。原因已经核实，按用户确认范围实施。
- 恢复融合前的线条厚实程度，保留每会话独立流光和状态配色。
- 重启忽略启动前的快照；本次启动后接收的运行状态仍持续保留。

# Non-goals

- 当前不删除用户快照、不改安装目录、不重启应用、不修改状态配色。
- 不把最后已知状态记录数宣称为已确认存活的线程数。

# Acceptance examples

- A1：Halo 启动时，磁盘已有的 thinking、executing、compacting、input_needed 等旧快照不产生流光或真实会话计数；反复扫描仍为空闲，不删除磁盘快照。
- A2：启动后同一历史会话收到新事件，或新会话产生事件时，正常显示对应流光；首次扫描期间产生的新事件不被当作历史快照丢弃，未来时间戳仍被拒绝。
- A3：本次启动后收到的运行与等待输入状态超过 60 秒仍显示；终态 3 秒退出、idle 60 秒失效、SessionEnd 移除及会话隔离保持。再次启动时，这些状态须等待新事件才重新显示。
- A4：同曲线同配置下，融合轮廓直接使用配置线宽；流光主体恢复厚度，去除 0.44 缩放和 2.4 固定上限。1、4 会话不因进入融合模式整体变成细线；13 会话仍保留各自亮芯和必要密度适配。
- A5：多会话配色、身份稳定、420ms 换色、进入退出、模拟隔离和 reduced motion 保持，1、4、13 会话在约 112px 及放大尺寸可检查。

- A6：外观动画设置提供可键盘操作的“光晕”开关；新配置及缺少该字段的旧配置默认关闭。关闭时不画外围光晕，开启时恢复光晕，主体厚度、配色、动画相位和空闲表现不变。选择立即生效、自动保存，切换设置页及重新加载后保持；非法非布尔值不得作为有效配置。

# Constraints and invariants

- 保留当前七种状态与自定义配色、数学曲线和动画参数。
- 不读取任务内容来猜测工作状态。
- 当前仅有 Hook 事件与匿名快照，未提供心跳或存活检测；无新事件不足以证明任务已结束。

# Decisions

- 当前 main 工作区开始时干净，无 active Native change；使用 current 隔离方式开展 Shape。
- 已证实：src/halo.js 的多会话轮廓宽度为 min(stroke_width, 1.2)，流光宽度为 clamp(stroke_width * 0.44, 0.65, 2.4) 再乘密度因子。旧轮廓直接使用 stroke_width，旧亮芯最大直径 7.2 个逻辑单位。
- 已证实：src-tauri/src/state.rs 对 thinking/executing/compacting/input_needed 不再按时间过期；旧合法快照会被重启恢复。默认状态本身仍为 idle。
- 本地只读现场发现四条 thinking 记录，其中包括 9 月 5 日与 9 月 7 日的旧记录。调查本身可能产生新 Hook，不能将调查时计数等同于用户启动瞬间计数。
- 现有归档规格明确保留无结束事件的运行状态，并允许重启恢复；修正该策略需要更新需求。
- 已运行 node --test src/halo-sessions.test.mjs：12/12 通过。现有测试验证当前游丝行为，不证明其符合本轮视觉期待。

- 用户回复“能接受”，确认上述修正范围及启动取舍：启动前已运行任务须等新事件再出现；运行期间丢失结束事件仍可能残留，不引入心跳或存活探测。

- 用户最新明确要求光晕作为配置项、可选择开启、默认不开启，替代直接删除光晕的前一补充。采用 glow_enabled 布尔字段，默认 false；复用现有开关、自动保存和设置事件，不新增模式或依赖。
