# 目标

将曲线选择按 10 个曲线族组织，保留原 20 个预设为族内快捷配置；将几何参数、参数重置和公式与曲线选择放在同一区域，减少重复选择项和跨区调节。

# 范围

- 在现有 Appearance / 外观视图内调整分区，不新增设置导航页。
- 曲线方案区按当前缩略图与族名/预设名、更换入口、曲线参数与独立重置、只读公式的顺序呈现。
- 渲染器区呈现透明度和六项动画参数：粒子数量、尾迹跨度、循环时长、脉冲时长、旋转时长、描边宽度。
- 图库顶部展示 10 个曲线族轮廓和名称；单款显示“直接使用”并一次激活即应用，多款显示数量并展开下方变体。
- 10 族为 Thinking、Rose Orbit、Rose、Lissajous、Lemniscate、Hypotrochoid、Butterfly、Cardioid、Heart Wave、Spiral Search。Hypotrochoid 包含原 Hypotrochoid Loop 和四个 Petal Spiral；完整映射见曲线规格。
- 保留全部原预设 ID、几何默认值、动画默认值、现有参数范围和可用性；族归属从预设推导，不增加持久化字段。

# 非目标

- 不增删原预设，不增加自定义预设保存、逐预设历史、搜索或收藏。
- 不将不同呼吸、旋转或路径方向规则强行统一，不扩展现有参数白名单，不重写数学引擎。
- 不重做视觉体系，不改状态颜色、插件集成、位置拖拽或顶层导航。
- 不增加第三方依赖，不发布、推送或创建 PR。

# 验收示例

- A1：仅改变图库的多款族浏览目标并关闭图库，再次打开时定位实际当前预设所属族；浏览目标没有保存成设置。
- A2：把透明度改为 0.65 后应用其他族的预设、重置曲线参数或重置动画，透明度仍为 0.65；动画重置只影响原六项动画值。
- A3：任一单款族经点击、Enter 或 Space 一次激活就应用唯一曲线，不要求再次点击；单款不展示重复变体区，打开当前单款时焦点落在顶部对应卡片。单款悬停和聚焦可预览但不保存。

完整目标规格保留已有能力的验收场景，并更新目录、参数归属、图库过滤和布局场景；以上补充跨能力边界和单款直接选择行为。

# 约束与不变量

- 20 个旧 ID 均可读取并正确回显到所属族；`curve_id`、`curve_parameters` 和六项动画设置沿用现有 Store、Bridge、串行保存与原生归一化。
- 应用另一预设加载其几何与六项动画默认值；再次应用当前预设不重置自定义值。只浏览多款族、悬停、聚焦和关闭不能保存。
- 几何重置只重置当前预设几何；动画重置只重置六项动画。透明度始终是独立全局值。
- 自定义几何继续同步到主页面缩略图、当前项预览、只读公式和桌面光环；非法输入、保存失败、较早响应与外部事件继续遵循现有边界。
- 使用现有暗色视觉、系统字体、原生按钮和滑块；中英文、键盘、减少动态效果、响应式布局均保留。
- 方案与布局共同影响曲线选择和参数展示，作为单个 Native change 推进，不拆分 Supervisor/Child。

# 决策

- 用户已认可按曲线族组织、原预设作为族内快捷配置，并提出将曲线参数归入曲线方案区。
- 采用同一外观视图中的语义分区；公式随几何参数移动。透明度放入渲染器，保持独立重置边界。
- 用户在查看图形网格与缩略图侧栏对比后，明确选择推荐的图形网格；替换原族下拉方案。
- 图库顶部常显 10 个曲线族轮廓，桌面 5 列 2 行；多款族点击只浏览，下方显示 2 至 5 个变体；单款族点击即复用现有应用路径，成功关闭、失败保留重试，当前项重选保留自定义值。
- 用户进一步要求单款直接可选，去掉重复点击。单款卡片作为唯一预设入口，保留悬停/聚焦预览和当前自定义几何；多款族轮廓保持首个预设默认静态图。单款时隐藏重复变体区，Tab 排除隐藏控件。
- 族网格与变体网格各自支持方向键、Home/End 和原生按钮激活，Tab 在关闭、族网格、变体网格和有效重试间移动。窄屏减少列数并纵向滚动，打开时当前项可见，关闭操作可达。
- 原有预设是带名称的几何和动画组合；合并用户选择层级不要求改写旧 ID 或引入通用公式开关。
- 当前工作区起始干净，使用 Runtime 默认 current，目录为当前仓库，分支为 main。
- 本轮确认来自用户对已展示可交互图形网格方案的“可以”；既有曲线参数布局、保存兼容、重置边界及验证预期持续适用。
