# 目标

移除设置页的 X 偏移、Y 偏移手动调节功能，改为直接拖拽桌面光环：macOS 按住 Command + 鼠标左键，Windows 按住 Ctrl + 鼠标左键。

# 范围

- 删除 Appearance 中两个偏移滑块、数值输出及对应的中英文标签，保留现有设置布局和其他控件。
- 为桌面光环增加平台修饰键配合左键的拖拽；未触发拖拽时维持鼠标穿透。
- 拖拽结束自动保存位置，重启恢复；已有安装的有效位置继续沿用。
- 保留设置页与托盘的“重置位置”，回到现有主屏默认位置。
- 支持在已连接屏幕间移动，处理不同缩放比例、负坐标和屏幕断开后的可达性。
- 更新当前涉及的完整目标规格：`overlay-positioning`、`settings-sliders`、`settings-workbench`。

# 非目标

- 不增加位置数字输入、拖拽开关、快捷键配置或新设置分区。
- 不改变曲线、七种状态颜色、动画、插件安装及应用生命周期行为。
- 不新增 Linux 支持，不执行发布、推送或远程 Windows 构建。
