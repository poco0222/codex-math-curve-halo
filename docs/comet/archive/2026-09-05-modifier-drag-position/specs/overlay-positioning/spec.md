# Overlay Positioning

## Purpose

通过平台修饰键配合鼠标左键直接调整桌面光环的位置，同时保留日常鼠标穿透、位置持久化和重置能力。

## Requirement: Modifier drag

macOS 使用 Command，Windows 使用 Ctrl。修饰键须在左键按下时已经按住，按下位置须位于可见光环的窗口区域内；拖拽保持鼠标与窗口的初始相对位置。单独按修饰键、从光环外开始的拖拽、普通左键以及右键/中键均不能启动移动。

松开左键或平台修饰键时结束拖拽。光环隐藏、关闭或拖拽被系统中断时，结束输入接管，不遗留拖拽状态。光环不夺取原应用的输入焦点，光环外的快捷键和鼠标操作保持正常。

## Requirement: Pass-through

光环平时保持鼠标穿透。拖拽仅临时接管符合条件的鼠标输入，结束后恢复穿透；不能要求用户先点击激活窗口、开启拖拽开关或关闭穿透。

## Requirement: Persistence and compatibility

拖拽完成时自动保存最终有效位置，重启恢复。读取旧配置时继续使用已有有效位置，不因旧 `offset_x`、`offset_y` 数据或兼容转换而丢失其他设置。内部坐标表示由实现决定，设置页不再提供 X/Y 偏移编辑。

修改颜色、透明度、动画或其他设置，以及此前已经排队的保存请求，都不得使位置回到旧值。位置写入复用设置保存的互斥、完整性和错误处理路径；失败保留上一次有效配置并报告错误，不假报已保存。

## Requirement: Reset

设置页和托盘保留“重置位置”。该操作恢复主屏右侧 28、底部 140 个逻辑像素的现有默认边距，并保存结果；不改变其他设置。

## Requirement: Monitor geometry

拖拽支持已连接屏幕，包括相对主屏的负坐标及不同缩放比例。跨屏时保持抓取点，不使用旧滑块的 `-2000..2000` 范围限制合法位置。结束拖拽后窗口保持可重新抓取；启动时保存位置不属于可用屏幕则回到可见的默认位置。

## Acceptance coverage

正式场景由 brief 的 A1-A6 提供：A2 覆盖拖拽手势，A3 覆盖穿透及焦点，A4 覆盖持久化和保存竞争，A5 覆盖旧配置及重置，A6 覆盖多屏及可达性。此处不重复生成相同验收项。

本次交付的验证证据范围以 brief 中用户已接受的验证预期为准；未执行的原生运行检查须保留 NOT RUN 记录。接受验证限制不改变上述功能目标，也不表示缺失的运行检查已经执行。

## Non-goals

不提供数字偏移编辑、可配置快捷键、新位置面板或 Linux 支持。不改变光环的渲染、状态来源、生命周期及集成功能。
