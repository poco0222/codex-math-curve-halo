# Outcome

一个主线程及其子代理共同占用一条连续流线。主头表达主线程最后已知状态；子代理状态作为尾迹内部的色段，表达所属关系，避免被误认为额外主线程。

# Scope

- 接入插件 SubagentStart、SubagentStop，并使用匿名父子身份隔离快照；复用现有 helper、状态目录、Tauri 合同、曲线和 Canvas。
- 子代理启动使用 thinking 作为生命周期活动初态，停止使用 completed 并沿用 3 秒反馈。其他事件只有明确携带有效 agent_id 时才能归属具体子代理；不推测宿主没有给出的精细状态。
- 主线程个数决定主头个数和流线间距；子代理只影响所属尾迹的颜色分布，不增加独立主头、不改变其他主线程的位置。
- 完成色段退出、主线程提前完成时子代理继续显示、SessionEnd 家族清理、重复事件、孤儿子状态、旧快照和非法身份兼容。
- 以既有动态预览为视觉方向：连续轮廓，一个主头，尾内柔和色段，112px 与放大视图，多个主线程各自独立。

# Non-goals

- 不新增宿主事件能力、会话内容读取、心跳、数据库、网络服务、运行依赖或设置面板。
- 不猜测普通工具事件所属的子代理；不宣称全部七态或所有宿主版本已完整接入。
- 不安装或升级用户当前插件和应用，不构建 Windows 安装包，不合并、推送或发布。
- 不用同状态合并或静默截断减少子代理；密集小尺寸不保证逐个数清。

# Acceptance examples

- Scenario: A1 同一 session_id 的主线程与两个不同 agent_id 的子代理事件写入三份独立匿名快照；子代理启动和停止不覆盖主快照；非法或缺失子代理 ID 不写父状态，普通主线程旧输入继续有效。
- Scenario: A2 主线程与子状态传入后，两个子代理只在该主线程尾迹内增加色段，主头保持一个；两个主线程各带子代理时恰有两个主头。乱序输入、重复更新不增加头或重置现有运动位置。
- Scenario: A3 子代理完成显示完成色并在既有有效期退出；主线程先完成但子代理仍活动时家族流线继续保留。父 SessionEnd 清理对应家族，不影响另一个主线程；仅收到子状态时按父身份形成一个家族，不冒充已知父状态。
- Scenario: A4 子代理色段只采用对应配置状态色，更新、增加和退出连续过渡；头部始终表达父状态。配置色修改同步生效，减少动态效果时保持静态多状态表达；同色或密集子代理仍保留数据身份。
- Scenario: A5 旧快照、普通独立线程、已有状态优先级摘要、模拟状态、启动时间边界、未来时间戳、运行态持续保留和光晕开关继续通过回归验证。
- Scenario: A6 实际 helper 按插件配置读取受控 Hook JSON，产出的父子快照能进入实际聚合与前端渲染合同；浏览器使用实际实现检查 112px/放大、浅色/深色、1/2 主线程、0/2/6 子代理和完成退出，无运行错误。记录真实宿主发射及 Windows 未验证范围。

# Constraints and invariants

- 使用现有 Rust/serde 和 vanilla JavaScript；不新增运行依赖。
- 保持父会话原 SHA256(session_id) 键。子代理键与父关联仅落盘匿名值，禁止写 prompt、原始身份、工具参数、响应或 transcript 内容。
- 不覆盖用户主目录的无关改动。当前实现工作目录为 Native 创建的独立 worktree。
- 颜色表示状态；主头与尾内位置表示层级；主线程之间维持既有独立运动，子代理没有独立空间运动。
- 同一身份的事件顺序仍受宿主已提供的信息限制，不新增无法从事件证明的存活或全序保证。

# Decisions

- 用户否定子代理各自一条独立流线，要求直接体现在对应主线程流线内部。
- 用户回复“可以”确认主头加内嵌色段方案；又回复“可以”确认动态预览，并在说明预览未接真实 Hook 后再次回复“可以”，授权进入正式接入与验证。
- 复用现有视觉系统；展示范围以明确身份和实际收到的事件为准，模拟示例不作宿主能力证据。
- 本 change 是一条紧密关联的采集、聚合、渲染合同，不拆 Supervisor Change；实施可在互不重叠文件中协作，统一验收。

# Open questions

无阻塞项。已确认视觉方向和接入范围。真实宿主发射及 Windows 安装版为交付时必须报告的验证限制。

# Verification expectations

新增行为先运行失败测试，再实现并通过测试。运行相关 Rust、Node 测试，现有渲染器校验、格式与 diff 检查；使用浏览器检查实际渲染实现。Builder 独立只读复核后提交候选，再由新的只读 Verifier 按 A1-A6 验收。
