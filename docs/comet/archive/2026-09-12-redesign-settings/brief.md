# Outcome

整体重做 Codex Halo 设置页视觉：参考 CC Switch 的分组、控件与留白，保留 Halo 曲线、深灰基调和少量暖橙强调。外观、状态颜色、集成、测试形成统一、紧凑、可扫描的工作区，保留全部现有功能。

# Scope

- 四页、全局语言/Overlay 开关/保存反馈，以及曲线选择对话框的视觉一致性。
- 外观保留“曲线方案 + Renderer”；Renderer 内以独立标题和分隔清晰呈现音频设置。曲线公式持续可见。
- 桌面四项侧栏、单一品牌区、随当前页变化的标题与用途说明；窄屏回流。
- 参考材料：https://github.com/farion1231/cc-switch/blob/main/src/components/settings/SettingsPage.tsx 。仅作设计与实现参考，不作为新增功能清单或逐像素复刻来源。
- 已核对 `src/settings.html`、`src/settings.js`、`src/settings-store.js` 和现有正式规格：已有四页按需挂载、重复品牌标题及完整功能控件。CodeGraph 提示控制器索引过期，已直接核对当前源文件。
- 受影响模块预计为 `src/settings.html`、`src/styles.css`、`src/settings.js`、`src/i18n.js` 及现有设置检查；正式规格为 `settings-workbench`、`settings-layout`。复用原生控件和现有控制器，不新增依赖。

# Non-goals

- 不新增导航页、主题切换、搜索、常驻预览、账户、供应商、代理、用量或备份功能。
- 不改变曲线算法、七种状态、设置字段、保存队列、IPC、音频采集/权限策略或后端。
- 不新增 X/Y 位置编辑器；位置仍通过桌面 Overlay 拖动及原有重置操作管理。
- 现有 `src-tauri/Cargo.toml` 未提交修改不归入本次改造。

# Acceptance examples

- A1：在默认 `1130×890` 窗口逐一选择四项导航，只显示一处 Codex Halo 品牌、当前页标题及用途说明；语言、Overlay 开关与保存状态在四页均可用，内容宿主仅挂载当前页。
- A2：四页采用相同深灰底、略亮分组面、标题/正文/辅助文字层级；主要标签和控件文字为 `14px`，暖橙少量用于选中或交互强调；滑块数值对齐，开关、按钮和次要重置操作跨页一致，无新增主题入口。
- A3：外观按“曲线方案、Renderer”组织；曲线入口、几何参数及重置、可见公式依次可达；Renderer 显示独立不透明度、六项动画参数、Glow、动画重置及清晰分组的音频控件。音频状态、强度禁用条件、帮助与重试入口按原规则显示。
- A4：曲线对话框可浏览全部现有家族/预设；浏览或取消不保存，应用保留既有参数及动画默认值规则和失败重试；切页/关闭后无残留绘制或重复绑定，不透明度不受应用或动画重置影响。
- A5：颜色页保留七状态主从编辑、色块/Hex、原生选色、预设和重置；非法 Hex 保留校验反馈且不保存，合法修改仅影响选中状态；切页后颜色及草稿不丢失。
- A6：集成页保留插件安装/卸载、操作中禁用与结果提示、诊断/导出、重置位置、登录启动和跟随 Codex；测试页保留全部七种状态模拟。操作调用原路径，失败可见且不显示虚假成功。
- A7：修改设置仍自动保存并显示 ready/saving/saved/error；初次加载、快速连续修改、切页及外部 `settings-changed` 不覆盖受保护的本地编辑、不抹掉未挂载字段，不引入额外保存或新 IPC。
- A8：在 `1130×890`、`760×760` 和 `390px` 宽视口中，用中英文检查四页与曲线对话框，无页面横滚、截断控件或重叠文字；键盘可导航、切换开关、操作滑块和关闭对话框，焦点与禁用状态可辨，错误/状态反馈可访问。

# Constraints and invariants

- 保留控件 ID、name、设置键、`data-i18n`、事件绑定及原生 input/select/dialog 语义；调整包裹结构时同步动态控件的局部样式接口。
- 不改变参数范围、精度、秒/毫秒和百分比转换；不通过重绘或重新挂载舍入已存值。
- 保留共享 store、初次加载保护、串行自动保存、部分事件合并、颜色草稿、曲线应用/取消/重试和音频订阅生命周期。
- 分组使用中性深灰背景上的略亮灰表面，不使用白色卡片；样式限定在设置页，避免影响桌面 Overlay。
- 风险：共用 CSS 可能影响 Overlay，动态参数/颜色行可能遗漏样式，页头重绘可能扰动焦点。通过作用域样式、保持挂载顺序及现有检查控制风险。
- 如需修改保存并发、IPC 公开契约、音频设备/权限、状态或曲线生命周期，标记高风险，实施前交 reviewer 预审并回到 Shape 明确范围；当前方案保留这些边界。

# Decisions

- 用户已选择当前工作区；沿用 `main`，不创建分支或 worktree。
- 用户已选择整体视觉重做，并统一整理现有四页；参考分组、控件和留白，保留 Halo 辨识度与全部功能。
- 采用四项桌面侧栏、单一品牌、当前页标题/用途，中性深灰与略亮分组面、14px 主体字、少量暖橙。使用紧凑设置行、细滑轨、对齐数值和 CSS 美化的原生 checkbox 开关。
- 使用单个 Native change；四页共享样式、挂载及国际化，独立子 change 会重复修改相同区域，无拆分收益。
- 实施顺序：统一 shell/视觉基础及双语页头；整理外观/音频/曲线对话框；统一颜色/集成/测试；检查响应式、键盘和行为回归。
- `settings-layout` 旧 Dashboard 网格由四页 shell 替代；`settings-workbench` 旧 unframed 措辞改为统一设置分组面。音频功能规格的行为保留，旧设置外观措辞按本次视觉规则统一，不扩展音频后端。

- 复用 `npm run check:settings-tabs`、`npm run check:renderer`，按实际变更运行 `node --test src/curve-parameters.test.mjs src/curve-picker.test.mjs src/audio-settings.test.mjs`；未运行或失败不得报告为通过。
- 浏览器检查三种视口、两种语言，记录截图及无横滚证据；覆盖动态参数、颜色错误、音频帮助、长诊断和对话框焦点。
- 使用现有测试或可控 bridge 验证自动保存、外部事件、曲线取消/应用及失败路径；涉及原生效果时在 Tauri 单独核实，浏览器模拟不等同插件安装、音频采集或 Overlay 已成功。
- 独立只读复核检查控制器/IPC/生命周期未越界、功能完整和 CSS 未污染 Overlay，再交 Runtime Verify。
