# Settings Workbench

## Requirement: Quick-setup shell and task structure

设置窗口 SHALL 面向快速配置后长期使用，只提供“光环 / Halo”和“连接与运行 / Connection & runtime”两个一级入口，默认打开光环。品牌只出现一次，全局启用、语言及自动保存反馈跨页面可达。只挂载活动页，共享设置保存全部字段。导航、折叠、预览选择和语言重绘本身不得产生设置写入；实际语言修改沿用保存路径。

光环页 SHALL 集中当前曲线入口、常驻本地预览、七状态选择与配色、直接可见的透明度和 Glow。几何参数及六动画参数位于默认收起的“高级调整”；各有独立重置，公式使用单独的只读 details 折叠。音频有独立可展开分组，遵守 System Audio Visualization。取消独立颜色和测试页，保留所有原有功能。位置继续通过桌面拖动和连接页重置，不增加偏移数值编辑器。

### Scenario: Complete visual setup in one View

- **WHEN** 用户首次打开光环页并选择曲线、微调透明度或 Glow、选择状态并修改其颜色
- **THEN** 操作和效果在同一页内完成，预览标明本地示例状态，常用控件无需打开高级调整
- **AND** 展开高级调整后可访问当前预设的几何、独立几何重置、六动画及动画重置，公式可单独展开
- **AND** 收起分组、切页及重新挂载不清除有效参数、音频配置或对应状态的颜色草稿

## Requirement: Local preview isolated from desktop state

光环页 SHALL 复用现有 renderer，以独立预览状态和当前有效设置绘制常驻预览。默认示例状态为 `thinking`，支持全部七状态；选择状态仅改变预览与相邻配色上下文，不调用 `simulate_state`、不写共享工作状态、不发送状态事件或保存。合法设置编辑仍按原行为即时自动保存，并可更新真实桌面的外观。

预览 SHALL 在桌面关闭时仍能查看，但明确说明桌面启用状态；预览不启动音频采集、不向 renderer 注入演示音频、不暗示真实接入。常驻预览复用页面已有有效真实音频帧，不新增订阅；无有效帧时回到原动画，桌面关闭不改变原采集暂停条件。音频真实反馈及效果范围遵守音频规格。预览不因真实任务事件自动跳到另一个编辑状态。减少动态效果时立即绘制可见静态首帧，位置静止而颜色反馈保留。打开图库时暂停背景预览，离开光环、页面隐藏或销毁时停止绘制并清理临时监听；返回后至多一个常驻预览循环。

### Scenario: Preview without interrupting a task

- **WHEN** 桌面正显示真实任务，用户切换七种本地预览状态，或桌面已关闭后继续预览
- **THEN** 本地效果与选中状态颜色一致，真实桌面工作状态及事件链不变，预览操作无模拟命令和设置写入
- **AND** 开关页面和图库、减少动态效果后，绘制暂停或恢复正确，无重复循环、订阅或采集器

## Requirement: Connection facts and retained runtime actions

连接与运行 SHALL 展示现有原生命令实际提供的状态、最后事件及时间、插件操作结果和错误，不推断在线状态、不新增插件扫描或接入状态机。无事件表达尚无可用事件，旧事件表达最后已知记录；安装成功仅表示安装命令成功，桌面测试成功仅表示测试命令成功。不能据此宣称真实事件链已接通。

首次打开设置 SHALL 提供简短、可关闭的接入说明及连接页入口，不先断言插件未安装，不强制向导、不阻止视觉配置。关闭仅保存前端界面偏好，不增加 AppSettings 字段；后续仍可从连接页查看说明。

安装/卸载、现有插件结果、登录启动、跟随 Codex 生命周期、重置位置、诊断刷新和导出 SHALL 保留原命令、载荷、进行中禁用、本地化成功/失败反馈。高级诊断内保留七状态“桌面测试”，明确操作影响真实桌面显示、测试不能证明接入且真实事件可覆盖测试；不新增停止测试 API，不把 `idle` 冒充恢复真实状态。语言保持全局可达。

### Scenario: Inspect evidence and run diagnostics

- **WHEN** 用户关闭首次接入说明并查看连接与运行，或事件缺失、陈旧、安装/卸载成功或失败
- **THEN** 页面只表达实际返回结果与事件时间，提供已有相关操作，不把没有新事件误报断线或把说明关闭当作完成安装
- **WHEN** 用户展开高级诊断并明确执行任一桌面测试
- **THEN** 以原七状态值调用原模拟命令，成功更新已有诊断、失败显示错误，操作附近说明真实桌面影响

## Requirement: Latest-value saving and edit protection

设置 SHALL 复用 shared store、Bridge、现有串行保存队列与 `settings-changed`，不增加另一持久化路径。初始加载未完成的编辑、未挂载值、部分事件合并和活动编辑保护继续生效；非法颜色草稿留在所属状态，不入队。初始反馈为“修改后自动保存”，修改后明确显示保存中、已保存、保存失败。

普通保存失败 SHALL 保留最新有效编辑和对应错误，提供全局可见的“重试保存”。重试从队列实际执行时的最新共享设置构建负载，不重放失败旧快照、不重新加载曲线默认值，不提交非法草稿；处理中防止重复重试。较早响应不得把尚有新修改的配置标为全部已保存，失败不宣称成功。曲线加载/恢复的字段与失效规则由 Curve Preset Picker 定义。

### Scenario: Recover latest edits after save failure

- **WHEN** 用户修改多个字段，较早请求失败，继续编辑并触发重试，同时到达初始加载、部分设置事件或较早响应
- **THEN** 最新本地编辑、未挂载字段、有效颜色和非法草稿按原规则保留，队列最终提交最新有效值
- **AND** 全局反馈准确表达待保存和失败状态，重试期间不可重复触发，成功仅针对实际完成的最新保存

## Requirement: Accessibility and localization

两入口、分组、预览标签、状态、配色、公式、曲线对话框、运行说明、错误和诊断 SHALL 支持 `en` 与 `zh-CN`。导航与状态选择保留选中语义、方向键/Home/End、可见焦点；原生表单、details、对话框焦点约束及关闭后恢复继续成立。布局、朗读、对比度和窄窗边界按 Settings Layout；实时画面不得逐帧播报。
