# Settings Layout

## Requirement: Two-entry preview-led settings shell

设置窗口 SHALL 使用单窗口两入口 App Shell（应用壳层）：光环与连接及运行，默认光环。品牌只出现一次，全局 Overlay 开关、语言及自动保存反馈跨页面可用；只挂载活动内容，导航不写设置。光环页以本地预览为视觉焦点，常用透明度、Glow 和曲线入口明显可见；状态选择与配色组成相邻操作区，六动画和几何高级折叠、公式单独折叠、音频独立折叠。连接页按接入信息、运行选项、高级诊断组织，不再保留独立测试页。

宽窗 SHALL 让预览与编辑同时可见，预览随内容滚动保持关联。窄窗采用紧凑预览和顺序布局，避免固定区域占满窗口或覆盖焦点控件；状态选择可换行成紧凑网格，颜色编辑紧随选择区，不要求滚过七个大行才到编辑器。页面允许纵向滚动，不允许文档级横向溢出；导航空间不足时回流到内容上方。

### Scenario: Configure at supported sizes

- **WHEN** 两页面分别在 `1130×890`、`760×760`、`390×844` 及中英文下显示
- **THEN** 宽窗预览与编辑并排、窄窗紧凑重排，预览状态及当前编辑上下文明确
- **AND** 页面导航、颜色编辑、常用控制、折叠入口和全局保存反馈可读可达，无遮挡与横向滚动
- **AND** 展开公式、音频或高级诊断后长文本自然换行，当前焦点可滚动到达

## Requirement: Consistent restrained visual language

设置页 SHALL 沿用系统字体、中性深灰背景、略亮分组面、细分隔及少量暖橙强调；常规文字对比度至少 `4.5:1`，主要控件文字以 `14px` 为基准，辅助说明降低权重但保持可读。预览承担主要视觉表达，不通过重复品牌、重叠卡片和大型页头占用首屏。不新增主题、搜索、方案库或第三方 UI 依赖。

控件 SHALL 使用一致按钮层级、标签与值对齐、单位和精度明确，重置为次要动作并说明范围。原生 checkbox 开关保留 label、checked/disabled 语义和 Space 操作，原生 range 保留键盘交互。细滑轨不能缩小命中范围，交互目标至少 `24×24px`。选中、禁用、错误及本地/真实状态不能只靠颜色区分。

### Scenario: Scan and operate controls

- **WHEN** 用户扫读两页并调整滑块、开关、曲线或颜色
- **THEN** 预览、主要动作、标签、读数、辅助说明和重置具有稳定层级，无重复标题或品牌
- **AND** 文字对比度、目标大小、原生控件语义及可见焦点满足要求，错误与作用范围有文字表达

## Requirement: Preserve control behavior and scoped styles

设置视觉 SHALL 限定于设置窗口，不污染透明桌面 Overlay。共享设置键、命令、载荷、规范化、数值精度及秒/毫秒转换保留；内部 DOM 可按新结构调整，但绑定和验证同步迁移，不能让隐藏或未挂载值丢失。挂载、折叠、纯重排或导航不保存、不舍入数值、不产生重复监听。当前参数对应的只读公式始终可从独立折叠区取得。

### Scenario: Remount and synchronize

- **WHEN** 设置页加载、切页、折叠、语言切换或收到部分 `settings-changed`
- **THEN** 现有值与活动编辑保护保留，控件绑定、输出和标签关联有效，无额外保存和重复监听
- **AND** 桌面透明背景、曲线渲染和拖动定位不受设置页样式影响

## Requirement: Accessible order and feedback

视觉、DOM 和键盘顺序 SHALL 一致。导航和状态选择保留方向键及 Home/End；折叠控件支持键盘、展开状态可感知。可见 label 与输入、输出、错误关联。自动保存和离散操作状态可被辅助技术读取，预览帧和音量不逐帧播报。对话框保持焦点约束、Esc 退出和入口焦点恢复；页面卸载后回到有效导航。减少动态效果时保留静态效果与状态色反馈。

### Scenario: Use keyboard and reduced motion

- **WHEN** 用户仅用键盘浏览两个入口、七状态、全部折叠区及曲线对话框，并启用减少动态效果
- **THEN** 所有操作均可达，焦点顺序和选中语义准确，对话框退出后焦点有效
- **AND** 动画停止而配色、保存、错误反馈可用，中英文长标签不裁切或覆盖焦点
